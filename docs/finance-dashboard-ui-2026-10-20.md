# 财务看板展示优化（2026-10-20）

## 调整

保留红黑品牌、现有 /finance/dashboard 汇总接口及其审核通过账单口径，不修改后端、数据库或权限。

- 顶部合并为应收、已收、未收、逾期四项金额指标，去掉与金额无关的待审核/待开票说明。
- 新增收缴进度，直接列出已收、未收和逾期占未收比例；无应收分母时百分比显示 —，真实零收款仍显示0.0%。

- 保留账期应收/已收趋势，按连续自然月排列、缺失月份留空，不把账期已收金额误称为当月现金流。
- 租户表复用WorkspaceDataGrid，按未收金额排序，增加收缴率、欠款占比、跟进状态及对应租户账单入口。有bill:view才显示跳转；未收不等同于逾期。
- 增加本月快捷筛选、更新时间、数据范围与口径说明；失败显示错误与重试，清除旧范围数据，不用0代替请求失败。请求序号隔离过期响应，页面卸载时清理图表与监听。
