# B2 交互平面图制作手册

德汇创新中心的 B2 页面用同一套米制坐标展示整层建筑、核心筒和车库交通。切到俯视可以核图，切到轴测可以看空间关系，点选房间、车位或标注可以在右栏查规格。本文记录截至 2026-11-24、代码版本 `b263c4e` 的制作过程。各项尺寸和图纸差异另见[建筑模型核对记录](b2-architectural-model.md)。

## 1. 从每张图取得它能证明的数据

| 成品中的内容 | 取数依据 | B2 的制作方法 |
| --- | --- | --- |
| 楼层轮廓、墙柱、地坪 | A101 平面、A301 剖面 | 从建筑 PDF 的 CAD 图层读取矢量线和面。以横向 81.600 m 尺寸链计算统一比例，再用纵向 77.700 m 尺寸链复核。标高取自图注。 |
| 核心筒、房间、电梯厅、井道 | A101、A401 | 只取 A401 上部的 B2 平面，按轴线配准到整层。用 14 个柱截面的角点复核，最大偏差约 2 mm。沿房间内边描闭合轮廓，逐项录入名称、图号和图注规格。 |
| 车位、车道、分区 | 《车库 竣工图》原第 5、6 页 | 第 5 页逐排读取车位号、转向、箭头和横道，第 6 页核对 C、D 分区。用楼层外包范围配准扫描图，斜车位保留四角和朝向。扫描图量取的尺寸在右栏注明“估算”。 |
| 坡道 | A409 的 6–6 剖面、A410 的 7–7 剖面 | 先在平面定位可见段，再按剖面确定上坡方向。B2 的两处起坡段均为 3.60 m、坡度 7.5%，随后接入 15% 主坡段。 |

保留不同图纸各自的口径。例如 A101 建筑图有 **158 个车位轮廓**，交通图有 **148 个编号车位**。建筑视图使用前者，车位与车道视图使用后者。房间的名称、图注尺寸、模型剖切高度和台账登记面积也各有来源；图纸有差异时，在右栏并列写明图号和各自的数值。

## 2. 制作四个图包并关联楼层

在项目根目录运行下列命令。本次复建使用 Python 3.12、`pdfplumber 0.11.9`、`pypdf 6.21.4`。输入为桌面的完整竣工图目录，基本图包生成器也会读取各专业的图签索引。新建临时目录可保留现有图包，便于比较。

```bash
drawings="$HOME/Desktop/6.2.2 竣工图"
workdir="$(mktemp -d)"
python3 scripts/drawings/build_b2_model.py "$drawings" "$workdir/B2-A101.zip"
python3 scripts/drawings/build_b2_core.py "$drawings" "$workdir/B2-A101.zip" "$workdir/B2-core-A401.zip"
```

交通图采用人工核对后的编号和描点，空间规格也包含逐间核对的图注。这两份底稿保存在制作机的 `output/`，单独克隆仓库时需另行取得。下列命令把底稿复制到刚才的工作目录，使它们读取同一版底图并将结果写到同一处。交通脚本按本机原有路径查找《车库 竣工图.pdf》，源件移动后须更新底稿副本中的输入路径，并保留原图指纹核验。

```bash
cp output/b2-garage-private/build_garage.py output/b2-spec-private/build.py "$workdir/"
python3 "$workdir/build_garage.py"
python3 "$workdir/build.py"
```

| 关联顺序 | 图包 | 用途 |
| --- | --- | --- |
| 1 | `B2-A101.zip` · `model.json` | 整层底图、建筑和剖面原图、各专业索引 |
| 2 | `B2-core-A401.zip` · `core.json` | 与底图配准的墙、柱、线稿及 A401 原图 |
| 3 | `B2-garage.zip` · `garage.json` | 编号车位、车道、交通标线与两页交通原图 |
| 4 | `B2-space-specs.zip` · `spaces.json` | 具名空间的轮廓、图注和来源，同时引用 A101、A401 的指纹 |

首次建图时，在「楼宇空间管理 → 德汇创新中心 → B2 → 平面图」用“关联竣工图包”挂入底图，再使用对应的详图和规格入口。图包保存在受权限控制的楼层附件字段 `custom_floor_asbuilt`。读包时核对楼宇、楼层和底图版本；打开原图时核对 PDF 的 SHA-256。图包的解析、关联和读取见[楼层附件实现](../dehui-property-admin/src/components/spaces/floorDrawingArchive.js)。

## 3. 把平面轮廓变成可点选的模型

1. **先画几何。** 把图上的平面点映射到 Three.js 的 X、Z 轴，Y 轴表示高度。墙柱挤出至地坪上方 1.20 m，形成能看到内部的剖切视图。房间画地面和空间边框，电梯厅另设地面色，电梯井内放置朝向对应厅室的开顶轿厢示意。1.20 m 表示展示切面，实际净高应另查图注。[楼层场景](../dehui-property-admin/src/components/spaces/FloorScene.vue) · [空间剖切](../dehui-property-admin/src/components/spaces/spaceCutaway.js)
2. **再分清地面标线和可读文字。** 车位边线、人行横道和箭头贴在模型表面，随道路旋转；车位号和房间名锚定到多边形内部，通过相机投影到屏幕文字层。旋转、缩放或改变窗口尺寸时重新投影，因此文字始终水平。标注相互遮挡时优先显示所选构件。[交通标线](../dehui-property-admin/src/components/spaces/garageMarkings.js) · [文字标注](../dehui-property-admin/src/components/spaces/floorLabels.js)
3. **让图和右栏共用一次选择。** 每个可点对象带有类别和图元索引。点击时先检测文字，再用射线检测几何体；从下拉框选择也写入同一状态。模型、标签和右栏用同一强调色，右栏按对象来源给出规格及可打开的原图。桌面把右栏放在模型旁，工作区宽度不超过 800 px 时上下排列；正交相机按当前容器宽高和模型包围盒取景。[页面与布局](../dehui-property-admin/src/components/spaces/BasementDrawing.vue) · [规格字段](../dehui-property-admin/src/components/spaces/floorDrawingSpecs.js)

## 4. 在模型上加循环动作

**以弱电间为例。** 在空间图包里核对“弱电间”名称和房间轮廓。设备生成器按名称选取机柜，在轮廓内采样，选择距边界余量最大的位置，并按可用空间缩放。柜体和四层交换机面板使用简单几何体，给各层指示灯设置不同闪烁相位。柜体各部件继承房间的点选信息，点灯或机柜都能回到弱电间规格。送风和排烟机房采用同样的放置方法，改为转动叶轮；污水处理间放泵组，强电间放配电柜。[设备和车辆模型](../dehui-property-admin/src/components/spaces/floorMotion.js)

**以停车为例。** 从交通图读取四条连通车道的箭头位置，确定各行驶方向的中心线。用直线连接路段，用二次贝塞尔曲线过弯；入位曲线终点取目标车位四角的平均值。车辆沿路径切线朝向行驶，进入 103、117、168 号位后停留约 4 秒，再沿入位曲线倒出，接回主环线。三辆车错开相位，共用循环周期。换一个车位时，先核对开口朝向和相邻车道，再检查整圈。[路线和停车时序](../dehui-property-admin/src/components/spaces/garageDrive.js)

动作由浏览器本地时钟驱动，表达设备用途和通行过程。运行时可暂停，暂停后仍可旋转和点选；首次打开时尊重系统的“减少动态效果”设置。设备通断、机柜型号、车辆位置和出租状态如需反映现场情况，应分别接入对应业务数据。

## 5. 验收与下一层复用

| 验收位置 | B2 的复查动作 |
| --- | --- |
| 整层与核心筒 | 对照原图抽查同一根柱的落点。点电梯厅、弱电间及同名不同位置的机房，核对名称、选中颜色、右栏规格和原图入口。 |
| 交通模型 | 核对 060–207 的 148 个编号，C 区 69 个、D 区 79 个。沿一个完整循环观察车头方向、转弯、入位中心、停留、倒出及车辆间距。 |
| 阅读与交互 | 从轴测转到俯视、拖动旋转、缩放、切全屏，再用窄屏打开。检查文字正向、点击命中、规格栏可读；分别验证动画暂停、恢复及切换视图。 |

修改前端后，可在项目根目录执行 `npm --prefix dehui-property-admin run build` 和 `npm --prefix dehui-property-admin run test:components -- --maxWorkers=1`。图纸比例、图包配准、入位方向和文字遮挡仍需用实际楼层附件验收。

**用于下一层时**，可以复用相机、点选、规格栏、标注避让和设备小模型。先为新楼层确定图号、标高、两条独立尺寸链及详图配准点，再制作空间与交通数据。当前页面入口、读包校验、坡道参数和停车路线均有 B2 专用条件；接入新楼层时要按楼宇和楼层选择相应配置，并保留版本核验。实施顺序可以从“一间具名房间能在图上选中、能打开原图”开始，再扩展整层和动画。
