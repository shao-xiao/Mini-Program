# 微信后台《用户隐私保护指引》复制版

更新时间：2026-08-05

后台入口：
```text
微信公众平台 -> 小程序 -> 设置 -> 基本设置 -> 服务内容声明 -> 用户隐私保护指引
```

## 需要声明的信息类型

### 手机号
使用目的：
```text
用于小程序手机号快捷登录、租户联系人或物业员工身份匹配、预约联系与账号安全校验。
```

使用场景：
```text
用户在账号管理页点击“手机号快捷登录”，或在会议、看房预约提交前验证手机号时使用。
```

### 姓名/联系人信息
使用目的：
```text
用于工单报修、访客预约、看房预约、会议预约等物业服务办理和联系确认。
```

使用场景：
```text
用户提交工单、访客预约、看房预约、会议预约时使用。
```

### 选中的照片或视频信息
使用目的：
```text
用于工单报修时上传现场照片，帮助物业人员判断故障、维修或服务事项。
```

使用场景：
```text
用户在“我的工单/工单报修”页面选择或拍摄现场照片并提交工单时使用。
```

说明：
```text
当前代码实际使用 wx.chooseImage 选择或拍摄照片，没有使用 chooseMedia，也没有视频上传功能。微信后台如以“选中的照片或视频信息”作为统一信息类型，可按该类型声明；不要额外声明视频上传能力。
```

### 用户生成内容
使用目的：
```text
用于用户资料、工单文本描述、预约备注和现场图片等用户主动提交内容的物业服务办理、记录留存与服务跟进。
```

使用场景：
```text
用户提交个人资料、工单、访客预约、会议预约、看房预约或填写备注时使用。相关用户生成内容采用人工审核把关。
```

## 不要声明的能力

当前小程序代码没有实际调用以下微信隐私接口或组件，微信后台不要额外勾选：

```text
getUserProfile
chooseMedia
chooseMessageFile
getLocation
chooseLocation
openLocation
startLocationUpdate
camera 组件
recorder
视频上传
音频上传
```

说明：
```text
当前工单位置、会议室位置、房源位置等为用户手动填写或业务记录展示，不是微信定位接口采集。电子合同和发票文件为用户主动查看自己的业务文件，代码只使用 wx.downloadFile 下载后 wx.openDocument 打开，不作为用户上传文件能力声明。
```

## 审核驳回整改说明可填内容

```text
已按修改指引完成整改：手机号快捷验证前置页及相关入口已移除“微信”“官方”等平台品牌化文案，统一改为“手机号快捷登录”或“验证手机号”；页面未使用微信官方 Logo。原生手机号授权能力、用户主动授权、服务端手机号解析和身份核验逻辑保持不变。
```

## 发布前检查

```text
1. 确认后台已保存并提交《用户隐私保护指引》。
2. 确认“手机号”已声明，用于手机号快捷登录、身份匹配和预约联系。
3. 确认“姓名/联系人信息”已声明，用于物业服务办理和联系确认。
4. 确认“选中的照片或视频信息”已声明，用于工单报修现场照片。
5. 确认“用户生成内容”已声明，并填写人工审核把关。
6. 确认未勾选定位、录音、getUserProfile、chooseMedia、chooseMessageFile、camera 组件、视频上传、音频上传等未使用能力。
7. 确认生产后端已配置 WECHAT_MINIPROGRAM_APP_ID 和 WECHAT_MINIPROGRAM_APP_SECRET。
```
