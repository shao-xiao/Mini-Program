# 设备台账新增与归档规则

适用于德汇创新中心物业管理后台的设备台账，包括手工新增、批量导入，以及补充新设备类型时的目录维护。

## 新增一台设备

1. 按源台账或铭牌登记设备名称、编号和已知资料。已有现场照片可随档案补充。同一台设备已有档案时，通过原档案补全资料。
2. 按「首页分区 → 黄色分类文件夹 → 设备小类」找位置。同类设备沿用已有文件夹和小类，不同品牌、型号用各自的档案区分。
3. 登记类型明确时沿用原类型。原类型为「其他」或空白时，按设备本体和用途归档。只有品牌名、用途仍不明确的设备进入「待确认」。取得物业确认后补入对应分类，并在档案中说明归类依据。目录分类保留原始登记名称和类型。
4. 添加后打开相应文件夹，核对设备名称、编号、图标和详情。新增一条档案时，台账总数、该文件夹数量及对应小类数量分别增加一。已有档案调整分类时，全局总数保持一致。

## 目录位置

| 首页分区 | 分类文件夹，按显示顺序 |
| --- | --- |
| 楼宇机电 | 电梯、空调、配电、给排水、通风与净化、照明 |
| 安全与通行 | 消防、安防、出入口设施、充电设施 |
| 厨房设备 | 工作台与储物、制冷与制冰、热厨与蒸烤、备餐与保温、清洗与消毒、回收与转运 |

保留台账已有的自定义类型。有记录时才显示对应文件夹。新增的小类能放进现有文件夹时，直接补在该文件夹内。

| 设备名称 | 归档位置 | 判定依据 |
| --- | --- | --- |
| 特来电 | 安全与通行 → 充电设施 → 充电桩 | 物业已确认这条档案对应充电桩。保留「特来电」原名，使用充电桩简图。 |
| 单温水龙头、混合水龙头 | 厨房设备 → 清洗与消毒 → 水龙头 | 都用于取水与冲洗，两者在同一组内分别显示。 |
| 万能蒸烤箱用工作台 | 厨房设备 → 工作台与储物 → 工作台 | 设备本体是工作台，「蒸烤箱」说明配套用途。 |

## 展示与计数

- 首页保留经典 Windows 黄色文件夹，封面显示代表设备。单击文件夹查看同类设备，再单击设备查看档案。
- 设备优先展示已有实物照片，无可用照片时显示符合本体轮廓和辨识特征的简图。暂时无法确定实物的档案使用通用档案图标。
- 同类设备集中排列，每组从新行开始。组首左侧显示小类名称，中间使用淡灰色细实线，线尾写简短用途和组内数量，例如「水龙头 ─── 取水与冲洗 · 15 台」。数量随真实数据计算。
- 先对全部命中记录分组，再分页。默认在组内按设备名称、编号、档案 ID 排序。用户选择排序后，按所选顺序排列组内设备。跨页的小类仍显示该组的完整命中数。
- 「台账总数」按当前账号可见的全部设备档案计数，每条档案计一次。筛选时另列命中数，进入文件夹时另列当前分类数。无筛选时，各文件夹数量之和等于台账总数。

## 遇到全新类型时

在现有首页分区内确定归属，补上小类名称、线尾用途说明和实物图形。用一条该类型的真实档案核对从目录到详情的完整路径，并检查相似名称的旧设备仍归入原组。已有类型的日常新增直接使用台账录入或导入功能。
