# 访客预约页面空间利用率优化

## 改造范围

- 租户访客预约页移除与导航标题重复的介绍卡，个人预约历史直接作为首个内容区。
- 空历史记录合并为一行摘要，不再在零记录时显示“上拉加载更多”。
- 历史记录改为分隔线紧凑列表，补充预约编号、来访单位和车牌号；审核、二维码和取消入口保持原状态机。
- 服务端 Schema 驱动的 `dynamic-form` 新增显式 `compact` 模式：短字段两列，文本域、附件和多选字段跨整行。默认布局不变，其他业务页面不受影响。
- 租户名称兼容读取 `/mobile/visitors` 当前返回的 `profile.tenantInfo.name`，并保留旧字段回退。

## 业务边界

- 未修改 `/mobile/visitors` 请求、提交字段、租户/申请人服务端派生、状态流转、RBAC 或数据库结构。
- 动态字段仍完全来自 `/mobile/module-fields/visitors`，页面不复制服务端字段定义。
- 门禁二维码继续通过受保护文件接口下载，并保持 `320rpx × 320rpx` 显示比例及长按能力。
