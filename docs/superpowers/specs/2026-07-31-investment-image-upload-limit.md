# 招商房源图片上传上限调整

日期：2026-07-31

## 业务结论

- 招商房源 JPG、JPEG、PNG、WebP 图片的单张上限由 `5MB` 提高到 `20MB`。
- 前端选择文件时先校验类型和大小，超过上限时显示中文提示，不再发送无效请求。
- 新增/编辑房源的待上传图片区与已保存房源的图片管理入口使用同一上限。
- Spring Boot multipart 单文件上限仍为 `20MB`；生产 Nginx 已配置
  `client_max_body_size 25m`，用于容纳 multipart 请求开销。
- 不放宽图片类型校验，不接受扩展名和 MIME 类型不一致的文件。

## 自动化验收

  `单张图片不能超过20MB`；伪装图片继续拒绝。
