# 房间、楼层与全楼 3D 模型拼装规则

每个房间保存为一个可复用模块。每完成一层，再保存一个能独立打开、整体移动的楼层模块。待各层完成后，交付人按楼层索引组装整栋建筑。建筑、给排水、强电、弱电、消防等视图共用同一份房间几何、设备定位与规格，专业视图负责叠加各自的设施、管线和动画。

## 房间怎样放回楼层

- 沿用 B2 的米制坐标。X/Z 是平面，Y 向上，默认缩放为 1。房间 GLB 以局部原点保存，根节点的 `extras.module.floorOrigin` 是房间放回原楼层的平移量。保留原始朝向，移动整间房时，内部设备、标注和接管点跟随房间移动。
- 房间轮廓、设备型号、性能参数和有图注的标高均带来源图号。图面量取、图注明示、示意外形和待核数据分别标明。有设备性能参数时，机身尺寸仍须以厂家尺寸图或现场测量为依据。
- 同名或同类型房间可复用设备构造方式。每个实例使用自己的楼宇、楼层、房间标识、实测或图注参数和轮廓。更新某个房间后，在使用它的各专业视图同步核对。

## 每完成一层，保存什么

| 交付物 | 保存内容 |
| --- | --- |
| 楼层 GLB | 一层一个根节点，房间作为可识别的子节点；装入该层公共墙柱、楼板、交通空间及已完成的专业构件。同一构件只装配一次。 |
| 楼层清单 | 楼宇和楼层标识、模块版本、对应 GLB、房间及其版本、所用竣工图号和修订版、已完成专业、待核项。保留独立房间源件，方便局部更新后重组。 |
| 整栋定位记录 | 楼层局部原点对应的建筑轴线或控制点、平面朝向、本层基准标高及其相对整栋 ±0.000 的高度。记录本层根节点放入全楼时的平移量和绕 Y 轴的旋转角。 |
| 跨层接口表 | 电梯井、楼梯、坡道、管井及立管等接口的标识、专业、相邻楼层、端点局部坐标、标高和来源。公共构件或接口段写明归属层，未核对应关系时保留待核。 |

建议按楼宇、楼层和版本分别归档。例如 `B2/v1/B2.glb` 与 `B2/v1/楼层清单.json` 放在一起；建筑级索引记录每层采用哪个版本。楼层修改后保存新版本，再更新索引。正式模型与竣工图按项目现有楼层附件权限保存。

## 后续深化与逐层装修

每层分别保存竣工建筑底模、专业系统和装修配置。装修配置随楼层清单一起归档，记录楼层标识、方案版本、适用房间、引用的底模版本和资料来源。同一标准层平面可供多层复用，每层可以选不同的装修方案，同层不同房间也可指定不同做法。

| 后续变更 | 模型与清单如何更新 |
| --- | --- |
| 深化已有 GLB | 给原型保存新版本，沿用已有实例编号。记录本次更新的外形、材质、尺寸、动画或接口及其依据。楼层继续引用指定版本；采用新版的楼层更新自己的清单。 |
| 增加设备或装修构件 | 同型同尺寸的对象引用已有原型，为新增实物分配实例编号；外形或接口有差异的对象增加原型或变体。登记所属楼层、房间、米制位置、朝向及图纸或现场依据。 |
| 调整单层或单间装修 | 地面、墙面和吊顶饰面按本层做法配置；新增隔断、门、灯具及固定家具保存为可定位的实例。楼层默认配置可复用，同层房间的例外按房间编号保存。方案稿和已实施现状分别标记。 |
| 重新拼装 | 保存本次楼层版本及变更记录，保留上一版供回看。在目标楼层核对装修边界、完成面标高、门洞和设备检修空间。涉及移位或接管时，复核设备实例、专业端口和相邻层衔接，再更新全楼索引中的对应楼层版本。 |

例如，3F 电梯厅改铺石材、4F 电梯厅继续使用原做法，两层仍可共用电梯门原型。石材做法及完成面厚度记在 3F 电梯厅；如果吊顶同时降低，灯具、喷头和风口按各自已有实例核对安装高度。竣工底模作为两次装修之间的比较基准。

## 全楼怎样对齐

1. 选定全楼共同的轴网、朝向和 ±0.000 基准。每层用两个可辨识的公共控制点确定水平位置和朝向，再用第三个不共线的点复核，记录偏差。优先采用贯通轴线、柱心或井道角点。
2. 房间先按 `floorOrigin` 放回本层，再把楼层作为整体旋转、平移到建筑坐标。房间高差与楼层标高各应用一次。例如 B2 地坪为 −9.200 m，某房间完成面为 −9.250 m，则房间在本层取 −0.050 m，B2 根节点在全楼取 −9.200 m。楼层高度逐层取自标高或剖面图。
3. 楼层清单中的每个有效版本装入一次。上下层接口按图核对中心、上下端标高和去向。图纸有偏移、变径或转接段时按图保留，并注明承载该段的模块。
4. 验收时先单独打开该层，再与相邻层叠合。检查房间数量和位置、楼梯平台与井道是否衔接、楼板及公共墙柱是否重复、管线接口能否对应。换一个专业视图复查同一房间和设备的位置；有动画的模块另验播放与暂停。

## 专业主视图的 GLB 装配与验收

- 从同版楼层装配索引和模型清单加载共享建筑与专业 GLB，按实例与文件摘要核对。页签和同一系统的演示按钮共用这套实体，默认打开整层轴测。俯视和专业原图供对图使用。
- 在轴测下近看管身截面、弯头、竖向构件或末端，保留库内材质和高差。仅有平面走向的部分记录缺少的截面或标高依据。模拟流向沿已核路径叠加，显示高度与实际安装标高分别记录。
- 专业视图复用建筑页的房间及设备子树、位置、材质和动画。墙体淡化只作用于围护构件，房名避开设备。点击设备或房名后可在右栏查看详情并近看设备。
- 从实际交付入口逐个打开专业页和演示按钮。在同一设备间对照建筑页与专业页，点选设备，播放、暂停、继续，观察带动画部件的变化。再独立加载导出的楼层 GLB，检查设备与动画绑定。
- B2 可用「消防 → 自动喷淋 → 排烟机房（西侧）」检查管道、喷头和风机叶轮，用「弱电 → 综合弱电 → 弱电间」检查桥架、机柜和指示灯。其他楼层按本层图纸和库内实例选择复验房间。

## 各层管线按什么高度安装

平面图用于登记 X/Z 走向。每条进入楼层三维场景的管段还需登记竖向依据、上下游端点、标注所指部位及来源图号/版本。长度单位统一为米，图注截面可保留毫米。图纸与现场记录分别注明来源。

| 图纸给出的信息 | 入模方法 |
| --- | --- |
| 管中心、管顶、管内底、风管底或桥架底的标高 | 记录图注所指的部位和基准。根据实际截面将其换算为模型原点。若图注给出建筑标高，则本层局部 Y 为构件建筑标高减本层基准标高。|
| 梁下、板下、吊顶内安装 | 登记对应的梁、板或吊顶，以及净距量到的部位。由同位置结构剖面、详图或现场实测确定参考面后，再计算局部 Y。相邻跨的梁高各自核对。 |
| 埋地、重力排水、变标高或跨楼层 | 记录两端管内底或中心标高、坡向、水平长度、转折点和接口。按图纸坡度推算的端点须标明计算依据。坑内启停水位单独保存。 |
| 仅有路线、截面或未能定位的安装说明 | 保留原图号、图面端点、已知参数及待核项，安装标高保存为空。路线用于俯视对图。按尺寸制作的样段可以独立转动观察。运行演示单独标识示意高差。 |

B2 的 E401 桥架可作复核例子。该图标出两处直段截面和梁下安装距离。房间的楼层原点用于安放房间模块，桥架安装需要另查该段对应的梁底与安装参照。后续装修如改变吊顶，复核检修空间时仍以原管段的安装记录为准。

复建 B2 的实体附件时，以同一版「全目录模型清单.json」和「楼层与跨层装配索引.json」为入口。已核坑深的剖切件沿用房间 ID，清单保存原 GLB 的摘要。同一风口可同时出现在暖通和消防中，两个视图引用同一文件、同一平移和同一个出风面。应用按所选专业和所选构件读取附件。专业原图和实体附件通过楼层附件权限关联到后台。

```sh
python3 scripts/drawings/build_b2_objects.py \
  'output/全楼装配/全目录模型-r1' "$HOME/Desktop/6.2.2 竣工图" \
  'output/B2系统制图/全局复核/B2-空间与构件GLB.zip'
```

构建器默认从输出 ZIP 所在目录读取私有文件 `B2图元复核.json`。可从已交付的同版实体图包解出这份文件，或使用 `--survey` 指定它的位置。

原图修订后，先核对图签、引线、标高基准和图面配准，再生成新版本并登记清单摘要。更新附件时保留旧版文件。验收同一构件在专业平面、实体近看和所属专业下的 GLB ID、标高及所打开的原图。集水坑还要核对设备间入口导出的文件和附件原件具有相同的 SHA-256。

## B2 作为首个参照

B2 已有 24 个可独立导出的房间及空间模块。该批房间的拼接索引可用于验证楼层装配。整层 GLB 与整栋模型分别在对应装配阶段生成并验收。B2 的原图配准、设备制作和单间导出步骤见 [B2 交互平面图制作手册](b2-floor-model-authoring.md)。

专业运行示意在楼层坐标中叠加共用的房间轮廓、房名、管路及已定位 GLB。轴测、俯视、仰视、选中设备或播放时保留楼层场景；构件详情和原图入口位于侧栏。按原图号和图层展示工况环节。给排水仅高亮已登记的支路，消防补风口的箭头继承 M306/M207 实体出风面的朝向。水位演示读取集水坑 GLB 内的启泵及停泵控制线。局部演示的粒子速度、指示灯频率与工况切换时间仅用于观察。要表达现场系统的连续流向，仍须核对每段管路的接口、上下游及实际安装依据。

## 给排水设备模块

B2 的「给排水 → 设备间与流向」可以按所选设备位置导出 GLB。两处污水处理间复用建筑视图的同名模块。11 个集水坑单独导出，原点取自 P301 平面，泵组和水位参数对应 P202。水井沿用建筑用房模块。导出后用根节点的 `extras.module` 核对名称、单位、楼层平移及图纸依据。同层拼装时，按所属楼层和模块名称去重。

跨层设备先按所属楼层保存。消防泵房、生活泵房和屋顶消防水箱间分别引用 P501、P502、P503。大样可独立预览，缺少整层配准时将 `floorOrigin` 记为 `null`。按前述三点法完成配准后再纳入楼层。清单分别标明设备表参数、预留设备、图面量取尺寸和示意外形。

## 首批装配样例 · B2 西侧污水处理间

装配样例使用七类对象。设备与末端、管线与连接件、建筑与结构构件作为基础对象，设备机组、房间与功能空间、楼层、整栋与场地作为装配模块。设备及支路有独立点选标识。拆出的源件和已装入它们的总成分别保存，组装时选择一个层级引用，避免把同一设备叠放两次。

在仓库根目录运行下列命令。参数依次是原始竣工图目录、建筑与空间图包目录、给排水 v2 图包、已导出的房间 GLB 目录和输出目录。图纸和模型交付物保存在本地工程资料目录。

```sh
node dehui-property-admin/scripts/assembly/build-b2.mjs \
  "$HOME/Desktop/6.2.2 竣工图" output/b2-water \
  output/b2-fast/B2-plumbing-v2.zip output/b2-room-modules/B2房间模块 \
  output/全楼装配/B2-v1
```

生成器核对 A101、A301、A401、P301 原始 PDF 摘要，再根据已配准的几何构造七个独立 GLB。每个 GLB 导出后重新加载，检查节点、动画绑定和空间回放位置。装配清单记录文件校验值、源件平移和管线端点。B2 独立 GLB 的地坪为局部零点，首批建筑总成把这层放到 −9.200 m；整栋水平定位暂沿用 B2 底图基准。

用桌面浏览器打开生成的 `打开模型.html` 即可离线点选、切换轴测或俯视、播放压力排水流向。全楼入口当前只装入 B2。B2 含 24 个房间与空间，本批专业深化集中在西侧污水处理间至 YWL-2 的排水支路。流向沿两段 P301 图线展示。动画速度、管道外径、安装高度和机身外形为示意；邻层接口仍待登记。图线末端与立管符号中心的平面差值以米记入清单。
