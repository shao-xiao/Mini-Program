# 德汇创新中心 B2 建筑模型

入口为「资产管理 → 楼宇空间管理 → 德汇创新中心 → B2」。建筑模型占据首屏主区域。房间台账在模型下方展开，与竣工图构件分别计数。楼宇通过业务编号绑定，楼层通过所属楼宇和楼层号绑定。

从原图重建到交互验收的操作步骤见 [B2 交互平面图制作手册](b2-floor-model-authoring.md)。

## 专业目录

已逐张核对专业图签中的图名和图号。给排水为 P301、P302，强电为 E302，消防为 P401，弱电为 21-001。本次仅关联这些专业的索引。建筑原图 A101 和剖面 A301 可在「核对建筑原图」中打开。源文件读取时校验 SHA-256。

## 重建与归档

使用装有 pdfplumber 和 pypdf 的 Python 环境，运行下列命令，参数为本地竣工图目录和私有附件输出路径。

```bash
python3 scripts/drawings/build_b2_model.py "/path/to/6.2.2 竣工图" "/path/to/B2-A101.zip"
```

生成器对 A101 和 A301 使用已核对版本的指纹。图纸换版时先复核尺寸链、标高、图签和停车数，再更新指纹和提取规则。归档包包含模型清单和两张建筑 PDF。源图、模型坐标包和生产数据保存在受权限控制的楼层附件中。前端静态资源仅分发渲染代码。

首次关联复用 floors 工作区的附件字段 custom_floor_asbuilt。下载走现有 /api/files/{id} 权限检查。首次创建附件字段需有楼层编辑权限和自定义字段管理权限。已有数据可通过原有楼层工作区权限读取。

## B2 核心筒详图

A401 的上部平面采用 1:50。A402 至 A405 描述其他标高，A401 下部各节点另有比例。提取范围限于 A401 上部建筑平面。与 A101 的 14 个柱截面分别匹配，逐角最大平面偏差 2 mm。此值表示图纸之间的相符程度，现场尺寸需另行实测。

提取器以相对的两条墙边及贯穿其间的至少两条材料填充线确认墙段，得到 20 段可选剖切体。其余已提取的建筑墙边作为平面线显示。整层和局部使用同一米制坐标，核心筒构件显示 A401 矢量量取值。保留 1.20 m 的展示剖切高度。

```bash
python3 scripts/drawings/build_b2_core.py "/path/to/6.2.2 竣工图" "/private/path/B2-A101.zip" "/private/path/B2-core-A401.zip"
```

原底图包为楼层图模字段的第一份附件，新增详图为第二份，使用现有楼层权限读取。页面校验底图版本与附件坐标，打开 A401 时校验 PDF 指纹。

## B2 车库交通竣工图

车位与车道视图采用《车库 竣工图》第 5 页交通设施平面和第 6 页墙裙分区图。按图中印刷编号逐排核对 060 至 207，共 148 个一般小型车位。依第 6 页的分区边界，C 区 69 个、D 区 79 个。建筑模式继续读取 A101 的 158 个原图车位轮廓，两个视图各自使用其图纸版本。交通图号独立于经营台账、车位绑定和出租状态。

交通层以编号面、9 个车道或坡道显示段、方向箭头、中心线和两处人行横道表达原图。扫描图按平面控制范围配准，车位和车道用于图上定位；规格面板仅列有依据的编号、分区和图示方向。A101 上另核实了三处送风机房、车库管理用房和电梯厅，绘制可点选的空间剖切体。1.20 m 为展示剖切高度。

交通包作为受控楼层附件追加。按清单识别核心筒和交通附件，独立读取，校验建筑、楼层、底图版本和打开的 PDF。生产数据、扫描图和点位均在私有图包内。本地复建底稿与图包保存在项目的 output/b2-garage-private 目录。

## 图元规格与原图复核

右侧规格由选中的模型对象驱动。编号车位、交通方向和人行横道关联交通图原第 5、6 页，扫描定位尺寸显示为估算。建筑墙柱与详图柱位显示矢量量取值；核心筒总览显示轴线尺寸和柱角配准差。可从规格栏直接打开对应原图。

空间规格作为独立楼层附件 B2-space-specs.zip 保存。spaces.json 同时引用 A101 和 A401 的来源指纹，保存房间名称、点选轮廓、图号及逐条图注。基础附件继续兼容。前室面积等总图与详图的差异在相应空间内并列；未给出的面积或净高不从手工描绘轮廓推算。本地复核底稿在 output/b2-spec-private。

## B2 三维构件与标注

车位按交通图的实际四角绘制线框及编号。道路保留图示方向和横道。两处坡道在交通图配准的可见范围内绘制分段坡面，北侧依据 A409 的 6–6 剖面向东上行，东侧依据 A410 的 7–7 剖面向北上行。两者均由 3.60 m 的 7.5% 缓坡接入 15% 主坡。平面定位仍受交通扫描图的配准精度限制。

空间名称取自受控附件，锚定在对应多边形内部。空间外框使用 1.20 m 展示剖切高度，电梯厅采用独立地面色，井道内的开顶轿厢表示空间用途。轿厢尺寸、所在楼层及运行状态均未接入。旋转、缩放或调整窗口时重新投影文字，保留车道箭头的图面方向；重叠时优先显示选中对象，放大后可见更多名称。

## 设备与交通循环演示

设备按图包的房间用途显示示意模型。弱电间为交换机机柜，强电间为配电柜，送风及排烟机房为风机，污水处理间为泵组。指示灯与转子按本地演示时钟循环，设备外观及运动用于说明空间用途。

车位与车道视图使用附件中的车道方向箭头和编号车位中心构造闭环。三辆示意车分别进入 103、117、168 号位，停留后按进入曲线倒出并继续顺行。演示不写入车位绑定或设备状态。可在视角工具栏暂停与恢复，系统开启减少动态效果时默认暂停，后台及画面离开视口后挂起动画。
