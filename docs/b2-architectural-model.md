# 德汇创新中心 B2 建筑模型

入口为「资产管理 → 楼宇空间管理 → 德汇创新中心 → B2」。左侧房间来自物业台账。右侧建筑图元来自竣工图，两者分别计数。楼宇通过业务编号绑定，楼层通过所属楼宇和楼层号绑定。

## 比例与规格

| 核对项 | 图纸依据 | 模型处理 |
| --- | --- | --- |
| 平面比例 | 建筑 A101，图签 1:150，两个方向的外包尺寸标注为 81600 mm 和 77700 mm | 从原始 PDF 矢量坐标计算统一的米制比例。用第二条尺寸链独立复核，允许 3 mm 绘图取整误差 |
| 标高与层间高差 | A101 车库地坪 −9.200 m。A301 的 B1、B2 分别为 −5.400 m、−9.200 m | 显示标高和层间高差 3.800 m。墙柱显示自地坪起 1.20 m 的剖切体量 |
| 面积 | A101 图注 6278 ㎡ | 台账存在登记面积时并列展示，各自保留来源 |
| 停车 | A101 注明实际停车 158 辆 | 识别 A-Car 图层 146 个矩形和 12 个旋转四边形，核对数量、轮廓去重。图元序号独立于停车管理的业务编号 |
| 墙柱与内部线稿 | A101 WALL、COLUMN、STAIR、EVTR 图层 | 从成对填充三角形复原 17 个墙段、75 个柱图元。其余墙线及楼梯、电梯轮廓按平面显示。未经核实的净高、板厚和坡道纵断面留待深化 |
| 构件尺寸 | A101 原图点位 | 选中图元后依次列出四边量取值，显示精度 0.01 m |

## 专业目录

已逐张核对专业图签中的图名和图号。给排水为 P301、P302，强电为 E302，消防为 P401，弱电为 21-001。本次仅关联这些专业的索引。建筑原图 A101 和剖面 A301 可在「核对建筑原图」中打开。源文件读取时校验 SHA-256。

## 重建与归档

使用装有 pdfplumber 和 pypdf 的 Python 环境，运行下列命令，参数为本地竣工图目录和私有附件输出路径。

```bash
python3 scripts/drawings/build_b2_model.py "/path/to/6.2.2 竣工图" "/path/to/B2-A101.zip"
```

生成器对 A101 和 A301 使用已核对版本的指纹。图纸换版时先复核尺寸链、标高、图签和停车数，再更新指纹和提取规则。归档包包含模型清单和两张建筑 PDF。源图、模型坐标包和生产数据保存在受权限控制的楼层附件中。前端静态资源仅分发渲染代码。

首次关联复用 floors 工作区的附件字段 custom_floor_asbuilt。下载走现有 /api/files/{id} 权限检查。首次创建附件字段需有楼层编辑权限和自定义字段管理权限。已有数据可通过原有楼层工作区权限读取。
